Drop one or more plot-data JSON files below and see them rendered, without
installing anything or writing any code. This page runs entirely in your
browser - files you drop here are never uploaded anywhere.

Export the files with:

```sh
scope-profiler export plot-data run*.h5 -o figures --format json --with
```

Then drag `figures/*.json` (or a single file) onto the box below. Each file
gets its own figure, in the order you dropped them; `region_statistics.json`
renders as a summary table instead of a chart.

## Under the hood

This is the same recipe as [Deploying a profiling dashboard](/scope-profiler/guide/dashboard/), minus the build step: `buildFigure`
reads the `plot` field each exported JSON file carries and dispatches to the
matching builder, so one drop zone handles every plot kind without naming any
of them. Nothing here needs a server - the same `<div>` and `<script type="module">`
work in a plain `index.html` served from a bucket, which is the point of
shipping `@scope-profiler/plotly` as a dependency-free package in the first
place.

For a page that keeps several figures in sync with a theme toggle or a filter
box across repeated renders, see [Deploying a profiling dashboard](/scope-profiler/guide/dashboard/).
